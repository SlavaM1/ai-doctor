# Проверенные application patches

`inc62-safe-error-page.patch` — полный накопленный diff приложения aurelSpa относительно `a6c2b8faa36e27d3f7eb4e1a22cbdafd27560004`, не patch исходников AI Doctor. Содержит унаследованные обработчики и операторское завершение после остановки модельных попыток. Модельные бюджеты не сбрасывались.

SHA-256: `815824b5dfcf8152a5db94b4d19eda3b115ef4353ac3eb93a2a1bb5e3c2499b7`.

Перед применением к **отдельному чистому checkout aurelSpa** проверьте базовый SHA и `git apply --check`. Не применяйте patch поверх уже работающего исправления и не запускайте его в репозитории ai-doctor. Оригинальный пользовательский checkout автоматически не менялся; Git push в aurelSpa не выполнялся.

Результаты, границы проверки и история неудачных автономных попыток: [inc62-release-validation.md](../inc62-release-validation.md).
