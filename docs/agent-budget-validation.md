# Расширение бюджета и выход из повторного чтения — 17 октября 2026

## Причина остановки

Fix #75 остановился на прежних 30 model calls, Fix #76 — на прежних 60 tools. В событиях повторялись чтения тех же `MarketService`, `MarketController`, security и tests. Это ограничение оркестратора AI Doctor, а не исчерпание баланса провайдера. Тесты у последнего частичного patch не проходили: повышать лимит не означает объявлять такой patch готовым.

## Изменения

- Максимум модели: **200** вызовов на задачу, tools: **1000**.
- Максимум контекста: **128000**, ответа: **16000**; один одновременный LLM-запрос сохранён. Ограничение агентного цикла увеличено до **7200 секунд**, обязательная финальная валидация остаётся отдельной.
- Максимальные значения применены через реальный `PATCH /settings` и сохранены в SQLite; `.env` согласован с ними. Сохранённые значения переживают перезапуск.
- Вместо безусловного сохранения только трёх turns контекст держит до 24 полных turns, пока они помещаются в бюджет. Tool call/result не разрываются.
- Повторные чтения одной области файла не вытесняют всю исследовательскую память. Агенту показывается список уже прочитанных файлов и число шагов без изменений.
- После шести шагов без прогресса, даже с существующим частичным patch, отдельный JSON-вызов требует перейти к оставшимся правкам с текущими тестовыми ошибками. Между такими попытками остаётся доступ к source tools. Ошибочный JSON не навсегда запирает агента в режиме генерации patch.
- Не изменены: workspace, исходные задачи, счётчики, разрешение автодеплоя, проверки test/hash/image, rollback, запреты изменения policy/config/migrations через агента.

## Применение и проверки

- Пересобраны/перезапущены **только API и frontend**, без замены Spring, MySQL или Mailpit. Перед перезапуском проверено отсутствие активных fix/deploy.
- Fix #76 сохранён в `job-76`: **27 model calls / 60 tool calls** уже потрачены, после увеличения осталось **173 / 940**. Patch и его SHA не изменились. Автодеплой в этой задаче был выключен и не включался автоматически.
- Playwright подтвердил доступную кнопку **«Продолжить в пределах лимита»** и отображение новых значений/максимумов в настройках. Кнопка не нажималась: продолжение запускается пользователем с сохранением исходной цели и расходов. #75 superseded — продолжать нужно последнюю #76.
- Backend: **220 passed**. Frontend: **19 passed**, production build успешен. Дополнительный regression test воспроизводит зависание на шести одинаковых чтениях и проверяет переход к правке/успешным тестам за 8 модельных шагов. Это mocked provider, а не обещание успеха любого реального DeepSeek-запуска.
- Evidence: `.runtime/expanded-agent-budget.json`, `.runtime/expanded-budget-continue-ready.png`, `.runtime/expanded-budget-settings.png`.

Бесконечный режим не включался. Больший бюджет может увеличить расходы и не гарантирует успешного исправления; provider/context/time limits и ошибки тестов по-прежнему могут остановить задачу. Произвольного сброса уже потраченного бюджета нет.
