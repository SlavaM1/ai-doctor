# Проверка цикла исправлений — 17 октября 2026

## Исправленные причины сбоев

- JSON-генерация patch больше не завершает агента до получения результатов тестов. После каждого нового hash runner запускает проверки; компиляция, assertions и причины ошибок Spring возвращаются агенту.
- Read/search доступны и при исправлении тестов. `file_list` позволяет узнать реальные пути без широкого чтения. Известные ошибки валидации runner передаются с объяснением, но произвольные HTTP bodies и credentials не раскрываются.
- Продолжение использует тот же workspace, актуальный diff и прошлые проверки. Уточнение цели из формы не создаёт пустое исправление, если выбрана последняя остановленная job с оставшимся бюджетом.
- В консольном выводе сохраняются начало и конец; JUnit XML отдельно отдаёт сообщения и вложенные причины падений. Диагностика деплоя сохраняется в контексте последующих шагов. После двух шагов без изменений отдельная JSON-генерация возвращает агента к правкам.
- Проверка деплоя больше не принимает INFO-класс `ExceptionTranslationFilter` за ошибку `Exception`. Реальные ERROR/stack-trace tokens и fingerprint по-прежнему проверяются.
- Автодеплой требует предварительного явного согласия для конкретной задачи. Пустой patch, непрошедшие тесты и несовпадающий hash запрещают выпуск. Подтверждённый сбой сборки/успешный откат возвращают задачу агенту; неизвестное состояние, HTTP 5xx runner и сбой отката останавливают автоматизацию.
